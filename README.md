# 🛍 Ecommerce UK Retail Data Project

**Análisis Exploratorio · Insights Estratégicos · Segmentación RFM**

---

## 📌 Descripción del Proyecto

Este proyecto analiza más de **540.000 transacciones reales de un e-commerce del Reino Unido** registradas durante el periodo **diciembre 2010 - diciembre 2011**.  
El objetivo principal es comprender el comportamiento del mercado, identificar patrones de compra y generar insights accionables que aporten valor en decisiones comerciales y de marketing.

---

## 🎯 Objetivos del Análisis

- Evaluar el desempeño general del negocio (ingresos, clientes y productos)
- Identificar **patrones temporales**: estacionalidad, días de mayor demanda y horas pico
- Analizar el comportamiento geográfico de las ventas
- Realizar **segmentación de clientes mediante RFM**
- Extraer insights clave y proponer **recomendaciones estratégicas**

## 📊 Insights Destacados

- **Noviembre presenta el mayor volumen de ventas** → fuerte estacionalidad por compras navideñas.
- La mayor actividad ocurre entre **10:00 y 15:00 hrs**, indicando ventanas óptimas para campañas.
- Reino Unido concentra la gran mayoría de ingresos → oportunidades en expansión internacional.

---

## 🚀 Recomendaciones Estratégicas

- Implementar programas de fidelización para clientes de alto valor
- Campañas estacionales con mayor foco en Q4
- Cross-selling durante horas con actividad pico
- Reactivación de clientes con alta recency
- Potencial de expansión comercial hacia Europa: DE / FR / ES
